## 3D Model Repositories

- [Printables](https://www.printables.com/) - Community platform for sharing printable 3D models.
- [Thingiverse](https://www.thingiverse.com/) - Large repository of free 3D printable models.
- [MakerWorld](https://makerworld.com/) - 3D model sharing platform with integrated print profiles.
- [Thangs](https://thangs.com/) - 3D model search and sharing platform.
- [MyMiniFactory](https://www.myminifactory.com/) - Curated 3D printable models and creator marketplace.

## CAD & 3D Modeling

- [FreeCAD](https://www.freecad.org/) - Free, open-source parametric CAD software.
- [Tinkercad](https://www.tinkercad.com/) - Beginner-friendly browser-based 3D design.
- [Onshape](https://www.onshape.com/) - Cloud-based parametric CAD platform.
- [Blender](https://www.blender.org/) - Free, open-source 3D modeling and sculpting.
- [OpenSCAD](https://openscad.org/) - Script-based solid 3D CAD modeling.

## Slicers

- [PrusaSlicer](https://www.prusa3d.com/page/prusaslicer_424/) - Open-source slicing software for FDM printing.
- [OrcaSlicer](https://github.com/SoftFever/OrcaSlicer) - Open-source slicer with advanced calibration tools.
- [Cura](https://ultimaker.com/software/ultimaker-cura/) - Popular open-source FDM slicing software.
- [Bambu Studio](https://github.com/bambulab/BambuStudio) - Slicing and printer management software.

## Printer Management

- [OctoPrint](https://octoprint.org/) - Web interface for controlling and monitoring printers.
- [Mainsail](https://docs.mainsail.xyz/) - Web interface for Klipper-powered printers.
- [Fluidd](https://fluidd.xyz/) - Lightweight Klipper web interface.
- [Moonraker](https://moonraker.readthedocs.io/) - API server for Klipper.

## Firmware

- [Klipper](https://www.klipper3d.org/) - Advanced 3D printer firmware.
- [Marlin](https://marlinfw.org/) - Popular open-source 3D printer firmware.
- [RepRapFirmware](https://reprap.org/wiki/RepRapFirmware) - Flexible firmware for compatible 3D printer controllers.

## Calibration & Testing

- [Teaching Tech Calibration](https://teachingtechyt.github.io/calibration.html) - Interactive 3D printer calibration guide.
- [Ellis' Print Tuning Guide](https://ellis3dp.com/Print-Tuning-Guide/) - Detailed guide to tuning FDM printers.
- [OrcaSlicer Calibration](https://github.com/SoftFever/OrcaSlicer/wiki/Calibration) - Built-in calibration workflows and documentation.

## Online Tools & Generators

- [Gridfinity Generator](https://gridfinity.perplexinglabs.com/) - Generate customizable Gridfinity storage components.
- [Lithophane Maker](https://lithophanemaker.com/) - Convert photos into 3D printable lithophanes.
- [HueForge](https://shop.thehueforge.com/) - Software for creating multicolor 3D printed artwork.

## File Repair & Conversion

- [MeshLab](https://www.meshlab.net/) - Open-source software for processing and repairing 3D meshes.
- [Microsoft 3D Builder](https://apps.microsoft.com/) - 3D model viewing and basic mesh repair.

## Resin Printing

- [UVtools](https://github.com/sn4k3/UVtools) - Resin print file inspection, analysis and modification.
- [Lychee Slicer](https://mango3d.io/) - Resin printing slicer and support tools.

## 3D Scanning

- [Meshroom](https://alicevision.org/#meshroom) - Open-source photogrammetry software.
- [Polycam](https://poly.cam/) - 3D scanning and photogrammetry platform.

## AI & 3D Generation

- [Meshy](https://www.meshy.ai/) - AI-powered 3D model generation.
- [Tripo AI](https://www.tripo3d.ai/) - Generate 3D models from text or images.

## Communities & Learning

- [r/3Dprinting](https://www.reddit.com/r/3Dprinting/) - General 3D printing community.
- [RepRap](https://reprap.org/) - Open-source 3D printing community and documentation.
- [All3DP](https://all3dp.com/) - 3D printing tutorials, news, and guides.
