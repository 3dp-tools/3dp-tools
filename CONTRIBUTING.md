
# Contributing to 3DP Tools

Thank you for helping improve 3DP Tools!

We welcome suggestions for useful 3D printing websites,
software, utilities, and resources.

## Suggest a Tool

1. Check that the tool isn't already listed.
2. Open a new GitHub Issue.
3. Select "Suggest a 3D Printing Tool".
4. Complete the requested information.
5. Submit your suggestion for review.

## Submission Guidelines

- Tools must be relevant to 3D printing.
- Websites should be accessible and functional.
- Both free and paid resources are welcome.
- Open-source tools are encouraged.
- Descriptions should be brief and objective.
- Affiliate and referral links are not permitted.
- Promotional submissions must disclose any affiliation.

## Editing the List

Pull requests are welcome!

Please keep entries organized alphabetically within
their categories and follow the existing formatting.

## Review Process

All submissions are reviewed by the repository
maintainers before being added.

We reserve the right to decline resources that
are irrelevant, misleading, unsafe, or excessively
promotional.

Thank you for contributing!
